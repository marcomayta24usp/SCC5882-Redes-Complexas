Dois componentes, dois zeros

λ₁ = 0, λ₂ = 0, λ₃ > 0

Vetores constantes em cada componente pertencem ao núcleo de L.

Isso é o caso ideal: grupos completamente separados tornam-se subespaços espectrais exatos.

Quando conectamos os componentes por poucas arestas, o segundo zero se desloca para um valor pequeno, mas positivo.

III · Particionamento espectral

Particionar o grafo: qual objetivo?

cut(S, S̄) = Σᵢ∈S,ⱼ∈S̄ wᵢⱼ

Minimizar apenas o corte favorece soluções triviais: separar um único vértice pode custar muito pouco.

Precisamos equilibrar separação e tamanho/volume das partes.
Objetivo. Um bom corte deve remover pouca conectividade entre grupos sem produzir uma partição degenerada. RatioCut e Ncut formalizam esse compromisso de formas diferentes.
[VL07] Graph cuts e motivação para objetivos balanceados.

Objetivos balanceados: RatioCut × Ncut

Tamanho

RatioCut

cut(A,Ā)(1/|A| + 1/|Ā|)

Penaliza grupos muito pequenos pelo número de vértices.

cut(A,Ā)(1/vol(A) + 1/vol(Ā))

Normaliza pela soma dos graus, incorporando heterogeneidade estrutural.

Intuição

Newman (2013): conexões entre formulações

Normalized cuts

Particionamento por objetivo de corte normalizado.

Modularity

Community detection via desvio do modelo nulo.

Inference

Community detection formulada estatisticamente.

Sob escolhas específicas de parâmetros e dentro das aproximações espectrais analisadas, Newman mostra que os algoritmos podem tornar-se idênticos.

O valor dessa observação é conceitual: métodos com motivações diferentes podem compartilhar a mesma estrutura algébrica.

Escopo do resultado. A equivalência discutida por Newman depende de aproximações espectrais e parametrizações específicas; não implica que os objetivos originais sejam idênticos em geral.

Código: Laplaciano + Fiedler

fiedler_demo.py
import networkx as nx
import numpy as np

G = nx.karate_club_graph()
A = nx.to_numpy_array(G, weight=None)
d = A.sum(axis=1)
L = np.diag(d) - A

# Laplacian eigendecomposition
lam, U = np.linalg.eigh(L)
v2 = U[:, 1]
labels_L = (v2 >= 0).astype(int)

print("lambda_2 =", lam[1])
print("groups =", np.bincount(labels_L))

X · Conclusão

Conclusões

1

O espectro é estrutural

Autovalores e autovetores codificam conectividade, gargalos e subespaços de grupos.

2

O operador importa

L e B respondem a objetivos distintos: cuts e modularidade.

3

Relaxar torna tratável

Problemas combinatórios são aproximados por autoproblemas de álgebra linear.

G → M → (λ,v) → estrutura
Resultado conceitual. Métodos espectrais são relaxações estruturadas: trocam uma busca combinatória por um problema algébrico cuja solução depende explicitamente do operador e do objetivo escolhidos.
